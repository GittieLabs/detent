| D-036 | 2026-11-07 | One HID interface carrying two collections: vendor channel (usage page `0xFF00`, report ID 6, 63 byte reports) and Consumer Control (report ID 4), plus CDC. | D-037 | 2026-11-07 | Strict decoding: `len` must equal the message's exact size, enum bytes must be defined values, bytes after the payload must be zero, HELLO control IDs must be unique, ENCODER delta can't be zero. | D-038 | 2026-11-07 | OLED text is printable ASCII only (`0x20..0x7E`) in fixed width, zero padded fields; menu labels 1 to 16 chars, status 0 to 20; `Label` and `StatusText` validate on construction so invalid text can't be encoded | Any byte 0 to 127 ("ASCII"); validating only at encode time | Control characters have no glyph on the SSD1306 font and would render as garbage.
